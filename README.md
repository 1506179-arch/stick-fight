# Stick Fight Game

A fun 2D stick fighting game with different colored sticks (Yellow, Blue, Green, and Red).

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" to begin
3. Use arrow keys or WASD to move your stick
4. Collide with opponent sticks to deal damage
5. Last stick standing wins!

## Controls

**Player 1 (Yellow Stick):**
- Arrow Up: Move Up
- Arrow Down: Move Down
- Arrow Left: Move Left
- Arrow Right: Move Right

**Player 2 (Blue Stick):**
- W: Move Up
- S: Move Down
- A: Move Left
- D: Move Right

## Game Features

- 4 different colored sticks: Yellow, Blue, Green, and Red
- Health system (100 HP per player)
- Collision detection for combat
- Real-time health display
- Smooth game loop at 60 FPS
